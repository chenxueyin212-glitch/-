## 三句话结论

1. **识别可靠**：训练期 45 次危机全部覆盖，封存验证期六段全部识别，其中两段提前 20 至 23 个交易日。
2. **类型判别不成立**：验证期确定可评价的两段判对零段，其中一段判成了相反的类型并执行了对应预案。这是明确写进报告的否定结果。
3. **预案有正的历史损益差，但它是上限**：方案一净损益差合计 +79.0 个单位净值百分点（26 年，折合年均约 +3.0），未计换手摩擦，且以事件结束日为已知输入。

## 两处需要读者注意的口径

**其一，验证期误报有两个口径。** 协议口径（2025-01-01 起，442 个交易日）为 19.8 个误报日/年；纯样本外口径（2025-04-08 起，381 个交易日）为 3.8 个误报日/年。前者含 30 个与冻结事件波及段重叠的误报日，不是纯样本外。两者不可互比，详见验证报告第六章。

**其二，论文中的“净损益差”不是收益率。** 它是逐事件单位净值损益差与误报段损益差的算术和，不是同一组合沿时间累积的收益率，也未处理重叠事件的资金占用。
